🔑 KEY PAYLOAD STRUCTURES
=========================

ANCILLARY PRICING REQUEST:
├── Travelers: [PAX1]
├── Query:
│   ├── OriginDestination: [Flight details]
│   └── Offers:
│       ├── OfferID: [original offer]
│       └── OfferItemIDs: [5 items]
│           ├── Flight item (refs: PAX1)
│           ├── Service 1 (Quantity: 1)
│           ├── Service 2 (Quantity: 1)
│           ├── Seat 1 (SelectedSeat: {...})
│           └── Seat 2 (SelectedSeat: {...})
└── DataLists: [traveler, fare info]

ORDERCREATE REQUEST:
├── Query:
│   ├── Passengers: [PAX1 with full details]
│   ├── OrderItems:
│   │   ├── ShoppingResponse: [offer reference]
│   │   └── OfferItem: [3 items]
│   │       ├── DetailedFlightItem (priced)
│   │       ├── OtherItem (service 1, priced)
│   │       └── SeatItem (seat 1, priced)
│   └── DataLists:
│       ├── ServiceList: [service definitions]
│       └── FareList: [fare groups]
└── Payments: [payment details]

🎯 DATA TRANSFORMATION
=====================

ServiceListRS → Ancillary Pricing:
- ObjectKey → OfferItemID value
- Associations → refs array
- Price → Quantity (for services)
- Seat details → SelectedSeat object

SeatAvailabilityRS → Ancillary Pricing:
- ObjectKey → OfferItemID value
- Location → SelectedSeat.Location
- Characteristics → SelectedSeat.Characteristics
- Associations → SeatAssociation

Pricing Response → OrderCreate:
- PricedFlightOffers → ShoppingResponse
- OfferPrice items → OfferItem array
- Service definitions → DataLists.ServiceList
- Seat definitions → DataLists.ServiceList

🔍 PAYLOAD BUILDING PROCESS
===========================

1. ANCILLARY PRICING BUILDER:
   - Takes FlightPriceRS (flight details)
   - Takes ServiceListRS (selected services)
   - Takes SeatAvailabilityRS (selected seats)
   - Combines into single pricing request
   - Each service gets Quantity: 1
   - Each seat gets SelectedSeat object

2. ORDERCREATE BUILDER:
   - Takes pricing response (main data source)
   - Takes ServiceListRS (service definitions)
   - Takes SeatAvailabilityRS (seat definitions)
   - Builds complete order with all items
   - Each item has proper pricing and associations

✅ SUCCESS CRITERIA
==================
- All selected services included in pricing request
- All selected seats included in pricing request
- Pricing response contains all items with correct pricing
- OrderCreate includes all items as separate OfferItems
- ServiceList in DataLists contains service definitions
- All items properly associated with passengers and flights
